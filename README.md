# 올팍 공연일 알림

올림픽공원 수영장·테니스장 등을 매주 같은 시간에 이용하는 사람이 이용 요일·시간을 한 번 정하면,
공연으로 주차가 붐비는 날을 달력에 미리 표시하고, 이용 요일의 공연일을 휴대폰 캘린더 구독으로 받아 볼 수 있게 하는 웹 서비스입니다.

- 서비스: https://olpark-alarm.github.io/
- 2026년도 한국체육산업개발(주) 공공데이터 활용 경진대회 출품용 시범 서비스이며, 기관의 공식 서비스가 아닙니다.
- 로그인·앱 설치·개인정보 수집이 없습니다. 설정은 이용자 브라우저에만 저장됩니다.

## 데이터

| 데이터 (한국체육산업개발(주)) | 쓰는 곳 |
|---|---|
| 2025 차량입출차·공연·날씨 연계 데이터 (오픈API) | 공연장·평일/주말별 '평소 대비 주차 배율'과 주차 증가 참고 시간대 |
| 올림픽공원 입출차 정보 (파일, 2024-07) | 보조 분석 (2025 결과를 다른 해 분 단위 자료로 확인) |
| 주차장 혼잡도 정보 (파일) | 시설 인근 주차장의 과거 만차 기록 비중 (참고 정보) |
| 잔디시설정보 (파일) | 정기 잔디 개방·통제 안내 |
| 월별주차현황 · 테니스장 이용 정보 (파일) | 이용 규모 근거 |
| 올림픽공원 공연/행사 일정안내 (누리집) | 공연장·기간·시간 → 달력·구독 (하루 1회 갱신) |

출처: 한국체육산업개발(주), 공공데이터포털·문화공공데이터광장 (공공누리 제1유형: 출처표시).

## 구성

- `index.html` · `app.js` · `style.css`: 화면 (외부 스크립트 없음, 글꼴 IBM Plex Sans KR · Google Fonts). 디자인 결정과 이유는 `DESIGN.md`
- `data/`: 배율 모델·공연 목록 등 (JSON), `feeds/`: 캘린더 구독 피드 (ICS)
- `build/build_data.py`: 연 1회 분석 (연계 데이터·파일 → 배율 모델)
- `build/update_schedule.py`: 매일 공연 일정 갱신 (인증키 불필요, `.github/workflows/update-schedule.yml`)
- `build/fetch_api.py`: 오픈API 원본 수집 (인증키는 저장소에 두지 않음)
